# 图片生成 3D Mesh 模型：以 Showcase 驱动的生产管线

与 Funcom 的合作始于一个真实的生产问题：概念板并不是干净的 3D 规格说明，而单次图片生成 3D 的推理结果又太不稳定，无法直接交给美术。概念板里可能有角色、多个视图、多个物体实例、地面或被遮挡的几何体。即便生成器重建对了物体，网格仍可能带有过多面数、碎片、破洞、非流形边或错误比例。

因此，这项能力的定位不是「一张图进、一个成品出」。它是一条带防护、保留人工决策点的流水线：清洗输入、生成多个形状假设、在候选中挑选、修复选中的网格，并验证实际打包出来的结果。

| 项目事实 | 当前证据 |
| --- | --- |
| 合作工作室 | Funcom |
| 主生成基线 | Hunyuan3D 2.1，同时评估 Hunyuan 3.1 与无标注多视图方法用于路由决策 |
| 数据基础 | 85 张原始概念板，整理为 90 张与模型对齐的目标图 |
| 冻结的端到端评测 | 26 个未见过的清洗后资产；26/26 完成，25/26 通过当前修复后的自动 QA 规则 |
| 最强的单项干预 | 在 25 个配对资产上，拆分多物体网格使平均归一化 Chamfer 下降 56.6% |
| 当前产品决策 | 推进受控试点；每个被接受资产所消耗的美术工时仍是主要业务 KPI |

## 1. 生产问题：每一处含糊的输入都会成倍放大下游评审成本

生成器必须从它拿到的像素里猜测：物体身份、实例数量、被遮挡的表面、各个视图的相机角色，以及背景边界。如果这些判断被留成隐含假设，流水线就会把算力花在生成好几个「错的东西」的版本上，然后在最昂贵的节点上让美术去诊断失败。

原始数据审计把这份代价摆到了台面上：

- 90 个目标物体中有 70 个在生成前需要裁切、去背景，或两者都做。
- 五张多主体概念板必须拆成 12 个独立目标。
- 一次早期原始运行从 85 张概念板生成了 473 个已保存候选，之后才进入选择与修复。常见失败包括人物或场景被烘进几何体、物体实例粘连，以及幻觉出的支撑平面。
- 错误的正/背面标注可能比不标注更糟：两张真实斜视角被硬塞进固定的相机槽位，产出了不对称或扭曲的几何体。

因此优化策略是把不确定性前移：尽早淘汰弱输入、在付材质成本之前先比较几何、并为语义正确性保留一个人工决策点。

## 2. Showcase A —— Atre Chair：用一个资产走完整条流水线

### 最终效果

- 归一化 Chamfer：**0.0015**。
- 与参考网格的离线对称一致性：**97.4%**。
- 修复后自动 QA：**通过**。
- 实际价值：美术拿到的是一个已修复的起始网格，而不是四个带贴图的候选加一项分诊任务。

这是一个代表性的留出（held-out）清洗评测结果。它展示的是完整工作流的价值，并不保证每张概念板都能达到同样的保真度。

## 3. Showcase B —— Atre OfficeTable：为什么必须有候选选择器

### 背景与失效模式

简单的网格健康度规则会奖励错误的物体。在这个案例里，一块平坦的支撑平面在技术上足够干净，因而拿到了很高的规则分，尽管它根本没有重建出桌子。

### 优化要点

一个 XGBoost 回归器用 590 个运行时可计算的特征为候选排序，且不需要访问目标真值网格：

| 特征组 | 数量 | 它贡献什么 |
| --- | ---: | --- |
| 网格统计 | 20 | 面数与顶点数、连通部件数、包围盒比例、面积、体积与分布统计 |
| 自动校验器 | 17 | 破洞、非流形边、退化面、重复面、碎片、法线、自相交与合规信号 |
| 对称性 | 26 | 镜像与 C2/C3/C4 特征，以及与检索到的邻近资产的差异 |
| 渲染视觉语义 | 512 | 在六个固定渲染视角上的平均 CLIP 嵌入 |
| 检索差异 | 15 | 与相关参考资产在形状、尺度、部件与相似度上的差异 |

回归器为每个候选预测一个连续的质量损失，并选择分数最低的那个。它不生成也不修复几何。

### 最终效果

- 规则选择的归一化 Chamfer：**0.024248**。
- 学习选择的归一化 Chamfer：**0.000741**。
- 单案例下降：**96.9%**。
- 在 64 个开发资产的资产级五折交叉验证中，学习式选择器取得的平均选中 Chamfer 为 **0.0237**，规则基线为 **0.0374**，均值低 **36.7%**。

64 个资产的结果属于开发集交叉验证，不是未触动的客户留出集对比。特征组消融实验是探索性的：其置信区间跨越零点，因此不应被解读为因果归因。

## 4. Showcase C —— Hark Shelves：在打分之前先拆分生成的网格

### 背景与失效模式

源概念图展示了架子的两个暗色、低对比度视图。为了让物体身份可被评审，两张准备好的视图被分开、做了轻度曝光校正，并在白色背景上呈现，而不是挤在原本灰暗的概念板里。生成器随后把两个视图作为独立体保留在同一个网格中，于是对完整网格打分等于同时度量了目标物体和那个粘连的伪影。只有把每个连通物体暴露成独立候选，目标架子才可能公平竞争。

*这些网格渲染使用相同的相机、素模材质与光照。这让被隔离的变化——两个生成的体对比一个选中的体——在不受贴图或暗背景干扰的情况下清晰可见。*

### 迭代与最终效果

该实验固定住被选中的源候选，只改变「在选择前是否把它拆成多个物体」这一个变量：

- Hark Shelves 归一化 Chamfer：**0.03741 → 0.000857**，下降 **97.7%**。
- Hark Shelves 表面 IoU：**0.0325 → 0.3749**。
- 在冻结的 25 个资产配对评测中，平均 Chamfer 从 **0.0373 变为 0.0162**（**−56.6%**）；20 个变好，5 个变差。
- 5% 阈值下的 F-score 提升 **53.6%**，表面 IoU 提升 **82.1%**。
- 在确定性修复之前，水密的源候选从 **10/25 提升到 25/25**（拆分并封顶之后）。

因为有 5 个资产变差，生产上会把原始的整网候选保留在池子里，并在拆物体置信度低时回退到它。

## 5. 修复解决了什么 —— 以及没解决什么

冻结的 26 资产运行端到端跑完了，但 **0/26** 个资产通过了首次修复前验证。修复不是一个可选的精修阶段；每个资产都至少触发了一类动作。在整个运行中，触发最多的是面数过多、退化面、小部件与非流形边。

修复之后，**25/26** 个资产通过了当前的自动化最终 QA 规则。然而，缝隙焊接检查显示只有 **19/26** 是完全水密的；七个仍留有真实开口或非流形区域。这暴露了一条规则缺口：当下游用途有要求时，水密性必须成为一道显式的硬门禁。

更重要的是，一个封闭且技术上有效的网格仍可能画错了物体。因此生产验收路径有两道独立的门：

1. **技术完整性** —— 拓扑、边界、碎片、法线、自相交、复杂度、尺度与打包。
2. **内容正确性** —— 交付的几何体确实表现目标物体，并满足工作室的视觉标准。

## 6. 证据汇总与解读边界

| 证据集 | 结果 | 它支持什么 | 它不支持什么 |
| --- | --- | --- | --- |
| 85 张概念板原始审计 | 473 个已保存候选；反复出现背景、多实例与地面失败 | 输入预处理与 QC 是必需的 | 清洗模型之间的受控对比 |
| 26 资产冻结清洗评测 | 26/26 完成；25/26 通过当前修复后自动 QA | 完整流水线能产出可供评审的起始几何 | 客户美术验收或美术工时节省 |
| 64 资产开发集交叉验证 | 学习式选择器平均 Chamfer 0.0237 对规则的 0.0374 | 学习式排序很有前途，且在该开发集上优于当前规则基线 | 未触动客户留出集上的提升或因果特征重要性 |
| 25 资产配对拆分测试 | 平均 Chamfer −56.6%；20/25 变好 | 物体拆分在几何上有很强的独立收益 | 保证每个资产都变好或带来视觉贴图收益 |

所有参考网格几何指标都基于独立居中并归一化、最长包围盒边长为 1 的网格。它们度量的是形状吻合度，而不是真实世界物理尺寸。自动 QA 同样不能替代美术验收。

## 7. 可复用能力与受控试点契约

可复用的能力是围绕生成所做的编排：

- 可审计的单主体图片准备与视图标签校验；
- 在单视图、可信固定视图与无标注多视图生成模式之间路由；
- 在投入贴图成本之前先做多候选生成；
- 无需目标真值的运行时候选排序；
- 物体拆分、确定性网格修复、归一化与打包；
- 技术 QA 加上针对语义正确性的显式人工评审。

对下一个工作室试点，成败应由**产出一个被接受资产所需的美术工时**来判定，并以修改负担、验收率、自动化技术 QA、算力成本与失败类别作为辅助指标。当前这些研究足以支撑启动该试点；它们尚未证明能降低生产成本。
