# 3D 重拓扑与减面：面向糟糕拓扑游戏资产的工具级探索

永星（Nikke）的合作暴露出一个反复出现的内容生产需求：游戏资产到手时是高面数、拓扑糟糕的网格，在能够复用之前必须重拓扑、减面，并整理出干净且左右对称的 UV。这向来是一项昂贵的手工活，因此团队探索了商用图片生成 3D 模型与开源重网格（remeshing）工具能否补上这段差距。

目前它还不是一项可投入生产的能力。本文档记录了做了哪些尝试、每个工具客观上产出了什么，以及差距仍在哪里。

| 项目事实 | 当前证据 |
| --- | --- |
| 合作工作室 | 永星（Nikke） |
| 输入资产 | 高面数测试件 —— 15,830 顶点 / 31,488 三角面，零四边面（纯三角面汤） |
| 目标要求 | 重拓扑 + 减面，外加左右对称 UV |
| 评估的工具 | Tripo、Meshy、Hunyuan3D、Quad Remesher（开源） |
| 最佳客观减面 | Quad Remesher + Tripo：15,830 → 1,159 顶点（−92.7%） |
| 当前结论 | 仅属探索 —— Tripo 在美术评审中排第一，但没有一个工具在拓扑与 UV 两项上同时达到生产质量 |

## 1. 生产问题：真正的阻塞是糟糕拓扑，不只是面数

一个「难以复用」的高面数资产，通常同时在三个方面不合格：面数太多、布线是三角面汤而非干净四边面、UV 布局无法镜像。单纯减面只能去掉面，修不了拓扑和 UV；任何需要干净四边面的下游流程（蒙皮、细分、动画、贴图镜像）都会拒绝一个「减过面但仍然乱」的网格。

测试资产让问题变得具体。输入的高面数资产——一件「糟糕拓扑」测试件——与原始资产逐字节一致，这意味着「乱布线」不是一个独立的缺陷：它就是原始资产本身，31,488 个三角面，零个四边形。

![输入的高面数糟糕拓扑资产 —— 纯三角面汤，31,488 三角面，零四边面](assets/images/3d-remesh/3d-remesh-input-highpoly.jpg)

*输入高面数资产叠加线框渲染。橙色线显示原始布线：不规则、不对称，且完全由三角面构成——没有可用于蒙皮或动画的干净四边面。*

## 2. 测量了什么

每个输入与输出网格都直接从文件解析（`.glb` 用 glTF 二进制，`.fbx` 用 FBX 二进制），提取顶点数、多边形数与三角面数。三角面与多边形的比值是判断拓扑类型的客观信号：比值 1.0 表示纯三角面，2.0 表示全四边面。

| 资产 | 顶点 | 三角面 | 拓扑 |
| --- | ---: | ---: | --- |
| 输入高模（糟糕拓扑） | 15,830 | 31,488 | 0 四边面 —— 三角面汤 |
| Quad Remesher | 7,304 | 14,432 | 全四边面 |
| Meshy | 2,419 | 2,880 | 未验证（已被三角化的 GLB） |
| Tripo 低模 | 1,326 | 2,584 | 三角面 + 四边面混合 |
| Quad Remesher + Tripo | 1,159 | 2,262 | 三角面 + 四边面混合 |

![各工具面数，按拓扑类型着色](assets/images/3d-remesh/3d-remesh-facecount.svg)

*各流程处理后的面数，按拓扑类型着色。在现有工具输出中，激进减面与干净四边面拓扑从未同时出现。*

## 3. 逐工具结果

### Tripo（商用）

Tripo 低模跑出了 2,584 个三角面，但其拓扑变成了三角面与四边面的混合。

![Tripo 低模输出 —— 2,584 三角面，三角 + 四边混合拓扑](assets/images/3d-remesh/3d-remesh-tool-tripo-lowpoly.png)

*Tripo 低模输出。面数很低，但布线仍不对称，表面是四边面与残留三角面的混合。*

### Meshy（商用）

Meshy 的输出（2,880 三角面）是单模型中减面最激进的结果。但保留下来的产物是被三角化过的 GLB，因此无法从文件验证其四边面结构，也没有 UV 对称性保证。

![Meshy 输出 —— 2,880 三角面，三角化 GLB，无 UV 对称保证](assets/images/3d-remesh/3d-remesh-tool-meshy.png)

*Meshy 输出。网格密集，剪影比输入更「软」；GLB 已被完全三角化，因此无法从文件还原其底层四边面结构。*

### Hunyuan3D（开源）

Hunyuan3D 在探索中被评估过，但结果目录里没有留下可保留的产物，因此这里记为「已评估、未测量」，而不给它一个面数。

### Quad Remesher（开源）

Quad Remesher 是唯一能把三角面汤干净地转成 100% 四边面的路径（7,216 个多边形对应 14,432 个三角面，比值正好 2.0）。它的短板是减面幅度：只去掉了输入约 54% 的三角面，还剩 14,432 个。把它与 Tripo 串联可把面数压到 2,262——这是测得的最佳客观减面——但最终拓扑又变成混合。

![Quad Remesher 输出 —— 14,432 三角面，100% 四边面](assets/images/3d-remesh/3d-remesh-tool-quad-remesher.png)

*Quad Remesher 输出。每个多边形都是干净四边面，但减面幅度温和（约 54%），布线仍不对称。*

![Quad Remesher + Tripo 输出 —— 2,262 三角面，三角 + 四边混合](assets/images/3d-remesh/3d-remesh-tool-quad-remesher-tripo.png)

*Quad Remesher + Tripo 输出。在 Quad Remesher 之后串联 Tripo 可把面数压到实测最低（2,262），但重新引入了混合拓扑，并带来一个小的旋转偏移。*

![重拓扑与减面探索流程](assets/images/3d-remesh/3d-remesh-exploration-workflow.svg)

*四条工具路径与核心结论：每条路径都在减面与拓扑之间做取舍，且没有一个强制保证 UV 左右对称。*

## 4. 工作室美术评审：主观结论

工作室美术团队评审了各输出并给出主观排序。这些判断是对上面客观面数的补充：

- **Tripo** —— 总体排第一，有三处待改进：布线左右不对称、网格存在破面、残留三角面过多。
- **Meshy** —— 布线杂乱且几乎全是三角面；更严重的是剪影没有被保留——眼睛和鼻子已经变形。
- **Quad Remesher + Tripo** —— 剪影像 Meshy 一样发糊，只是程度较轻；布线甚至略好于 Tripo，但拓扑仍不对称，模型存在明显的摆放/旋转偏移，且凹陷区域布线堆积。

总体排序：**Tripo > Quad Remesher + Tripo > Meshy**。

## 5. 为什么结果「平庸」——各项取舍

把客观测量与美术评审结合起来看，没有一个工具能同时满足所有要求：

1. **激进减面**由 Tripo 低模、Meshy 和 Quad Remesher + Tripo 实现——但代价是产生混合（部分三角化）拓扑。
2. **干净四边面拓扑**由 Quad Remesher 实现——但减面幅度很弱，且美术评审指出布线仍不对称、在凹陷区域堆积。
3. **剪影保真**（保持模型整体形状、眼睛与鼻子）在 Meshy 上失败，在 Quad Remesher + Tripo 上退化；只有 Tripo 让形状保持可辨识。
4. **UV 左右对称**没有任何工具实现；在每条路径里它都是一道手工步骤。

这就是「平庸」的具体含义：工具解决了容易的部分（去掉面），把困难的部分（对称拓扑、完整剪影、UV 对称）留了下来。

## 6. 证据汇总与解读边界

| 证据集 | 结果 | 它支持什么 | 它不支持什么 |
| --- | --- | --- | --- |
| 输入网格解析 | 31,488 三角面，0 四边面 | 输入确实是三角面汤，并非夸张 | 原始资产的视觉质量 |
| 各工具面数 | 随流程在 2,262 – 14,432 三角面之间 | 各工具在减面与拓扑类型上的客观差异 | 美术方向质量或 UV 正确性 |
| Quad Remesher 比值 | 7,216 多边形 → 14,432 三角面（2.0） | 该工具产出了真正的全四边面重网格 | 该四边面布线是否已达到可动画标准 |
| UV 要求 | 没有任何工具输出带对称性保证 | UV 对称是一处未解决的缺口 | 某个特定工具「在 UV 上失败」——UV 未按工具逐一测量 |
| 工作室美术评审 | Tripo 第一；其余存在剪影/布线问题 | 与客观数字一致的主观排序 | 逐像素或有指标支撑的视觉结论 |
